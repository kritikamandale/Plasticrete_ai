# Recording a cube test

This is a recording template. It does not contain measured results.

For each mix the studio saved as a batch:

1. Cast three 150 mm cubes.
2. Cure them with the cast date written on the batch passport.
3. Test one set at 7 days and the remaining cubes at 28 days.
4. Enter each cube's compressive strength on the batch page, not an average typed from memory. The store computes the mean and the coefficient of variation.
5. If the coefficient of variation is above 0.15, the API refuses the row until the form sends `confirm_high_cv`.
6. Photograph the cube and upload it on the same passport.

The standard named on the form defaults to whatever the lab writes. The store does not fill a strength.
